    04 Questions

    The short answers.

    Everything the studio does — and doesn’t — in plain language.

    What can I upload?

    MP3, WAV, M4A, FLAC, OGG and WEBM, up to 25 MB per file. Most voice-note apps and recorders output one of these already, so there is no conversion step.

    Where does my audio go?

    The studio holds your file in memory and sends it to Groq’s Whisper API for transcription. It is not written to disk, added to a library, or kept after the request finishes. There is no account attached to it.

    How precise is the timing?

    Each segment gets a start and end time in seconds. Accuracy follows the audio: clean speech with clear pauses aligns tightly, while music, crosstalk and heavy background noise are harder for any model.

    Which languages are supported?

    Automatic detection is the default, with manual overrides for English, Hindi, Spanish, French, German, Portuguese, Italian, Japanese, Korean, Chinese, Arabic, Russian, Indonesian, Turkish, Dutch and Polish. Whisper handles many more beyond that list.

    Can I edit the captions?

    The studio gives you copyable lines and clean exports. For wording changes, take the SRT or VTT into your editor — every timestamp stays intact.

    Do I need an account?

    No. Open the studio, drop a file, export. The only limit is the 25 MB ceiling per recording.
